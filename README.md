r# HRIS Analytics Dashboard

## Project Overview
This project focuses on analyzing Human Resources data using Databricks SQL. The goal is to transform employee data into meaningful insights and support HR decision-making.

## Tools & Technologies
- Databricks
- SQL
- GitHub

## Dataset
The dataset contains 600 synthetic employee records with information about:
- Department
- Job Title
- Employment Type
- Employment Status
- Annual Salary
- Performance Rating
- Absence Days
- Training Hours
- Overtime Hours
- Hire Date

## Key HR Metrics
- Total Headcount
- Active Employees
- Terminated Employees
- Average Salary
- Average Performance Rating
- Employee Turnover Rate
- Monthly New Hires

## SQL Analysis
The project includes SQL queries for:
- Headcount by Department
- Employment Type Analysis
- Employees by Location
- Monthly New Hires
- Average Salary by Department

## Dashboard
The HRIS dashboard was developed using Databricks visualizations to present key HR metrics and employee trends.

## Project Status
In Progress

## Note
This project uses a synthetic dataset created for educational and portfolio purposes. It does not contain real employee information.
